# Digital Petroleum — India's #1 Cloud Petrol Pump Software & AI Staff Ecosystem

🌐 **Live Platform:** [www.digitalpetroleum.shop](https://www.digitalpetroleum.shop)

**Digital Petroleum** is a next-generation Progressive Web App (PWA) designed specifically for Indian retail fuel stations (**BPCL, IOCL, HPCL, Nayara**). Built on **Firebase** and **Cloudflare Workers**, it solves ground-level forecourt accounting, nozzle meter reconciliation, shift cash tally, and credit (udhaar) recovery—replacing outdated, expensive Windows-only software like **PetroSoft**, **SOFTGUN**, and **Miracle Petro**.
